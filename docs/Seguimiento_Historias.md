# Seguimiento de las historias de usuario en GitHub Projects

El tablero se utiliza para mostrar el avance del **análisis y la documentación del TPI**. Los estados se refieren a la preparación de las historias, sus criterios de aceptación y su representación en el proceso; no significan que la aplicación de facturación ya esté programada o implementada.

## Distribución propuesta para evidenciar el recorrido

| Historia | Estado del tablero | Qué representa |
|---|---|---|
| HU-01 — Carga de factura | **Listo** | La historia, sus criterios de aceptación y el tramo de carga/verificación del BPMN están definidos. |
| HU-02 — Reconocimiento y revisión de datos | **En Progreso** | El reconocimiento y la revisión están modelados; se está mejorando y verificando el diagrama BPMN a partir de la devolución docente. |
| HU-03 — Validación y almacenamiento | **Por Hacer** | La historia está registrada en el backlog y queda pendiente avanzar con el próximo tramo de análisis y documentación. |

## Secuencia de estados
El tablero permite seguir el recorrido **Por Hacer → En Progreso → Listo**. Para que el recorrido sea visible, se actualizará el estado de cada historia cuando avance el trabajo y se conservarán los criterios de aceptación asociados.

**Aclaración:** el estado Listo de HU-01 indica que su definición y modelado documental están completos para esta etapa del TPI. No afirma que la funcionalidad esté implementada en una aplicación en producción.
